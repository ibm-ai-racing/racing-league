# IBM AI Racing League

Welcome to the **IBM AI Racing League** – a student competition where you build an AI driver that races in the open-source [TORCS](https://torcs.sourceforge.net/) simulator.

You write a Python agent that reads the car's sensors, decides how to steer, brake and shift gears, and sends those commands back to the simulator. Tune it, test it, and see how fast your car can go.

More information about the League: <https://ibm-ai-racing.github.io/>
