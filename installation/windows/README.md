# Windows Installation Guide

In this folder, you will find the installation guide for the Windows platform, covering the following steps:

1. **Prerequisites** — Hardware requirements, disk space, Python 3, Git, and C++ Build Tools

2. **TORCS + SCR** — Download and unzip (no installer required; just extract and run)

3. **Python Packages** — Create a virtual environment and install necessary libraries

4. **`gym_torcs`** — Set up the AI starter kit provided by the organizers

5. **IBM Bob** — Install IBM fork of VS Code editor with IBM AI Assistant , set Python extenstion
